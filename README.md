# Gustavo Pereira — Front-End Developer Portfolio

Welcome to my personal portfolio! This website showcases my web development projects, the services I offer, and a little about me as I continue to grow as a developer.

## About the Project

I built this portfolio to practice front-end development and present my work in one place. The site uses a dark visual theme with purple accents and a responsive layout for mobile and desktop screens.

## Features

- Responsive layout for mobile and desktop
- Mobile navigation menu with open/close behavior
- Projects section with links to published work
- Services section
- About section
- Contact links
- Subtle hover interactions

## Built With

- HTML5
- CSS3, including Flexbox and media queries
- JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use a local development server.
